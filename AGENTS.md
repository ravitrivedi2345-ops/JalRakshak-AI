# JalRakshak Watershed Monitoring Interface

React + Vite + Tailwind CSS dashboard for watershed monitoring and intervention tracking.

## Development server

Run the app with Vite and keep the default port at 8443.

## Project structure

- `src/main.tsx` - React entry point
- `src/App.tsx` - dashboard UI
- `src/index.css` - global styling and Tailwind import
- `index.html` - app shell
- `package.json` - project scripts and dependencies
- `vite.config.ts` - Vite configuration with React and Tailwind

## Dependencies

- React 19
- Vite 8
- Tailwind CSS v4
- Lucide React for UI icons

## Styling

Use Tailwind utility classes in JSX. Keep any global CSS in `src/index.css` and preserve the Tailwind v4 import first.

## Code quality

- Prefer double quotes in JSX text where needed.
- Keep components clean, typed, and exported as default exports.
- Ensure the project remains production-ready and free from template-specific branding.
